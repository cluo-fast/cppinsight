# CppInsight AI 公开测试准备清单

这份清单把源码已完成项与必须在目标环境实测的发布门槛分开。只有所有“发布门槛”都有证据，才可把安装包称为公开测试版。

## 已在当前工作区验证

- [x] C++ 扫描器稳定符号键、限定名、父作用域、调用归属、类型关系和入口点。
- [x] schema 2 兼容迁移、schema 3 图事实、完整 generation 事务回滚。
- [x] 统一 Graph Protocol v1：五类图、方向/深度/筛选、路径、循环、中心节点、证据和分页。
- [x] Tauri 异步 `query_graph`、布局保存/加载及稳定节点 ID 校验；概览、问答、摘要和符号分析命令均校验项目作用域。
- [x] 桌面 GraphWorkbench：五类图切换、搜索/筛选、缩放、拖拽、节点展开/收起、路径目标、证据面板、分页和 SVG/PNG 导出。
- [x] Cytoscape.js 3.34.1 已锁定并由 Vite 生产构建打包；图节点颜色、路径高亮和 zoom 控件已接入实例。
- [x] Cytoscape.js 按需动态加载，首屏主包与图渲染块拆分；加载失败时保留确定性 SVG 后备画布。
- [x] 接手报告加入模块、调用、包含、类型和入口图洞察，并带关系证据位置；提供入口符号/热点文件的确定性阅读顺序；支持 Markdown/HTML 摘要下载，AI 关闭时本地报告和图查询仍可用。
- [x] 索引完成或恢复已有索引后自动生成接手报告；生成期间有明确占位，失败时可手动导出重试，重新索引不会复用旧报告。
- [x] 索引任务支持取消：终止扫描子进程并保留上一份完整索引，首次索引取消后明确提示可重新索引。
- [x] 报告面板可按五类图直接打开对应关系图视图。
- [x] 符号分析结果携带稳定节点 ID，可直接定位到函数调用图；关系图节点仍可回到符号影响面和 AI 问答。
- [x] 从关系图节点发起的 AI 问答会保存稳定节点 ID，回答卡片可回到原关系图节点。
- [x] 欢迎页提供内置示例项目入口，首次体验不需要命令行或准备外部仓库。
- [x] 设置页显示运行版本、隐私边界和 GitHub 反馈入口，并支持脱敏诊断预览/导出。
- [x] 每次 AI 请求发送前展示将使用的本地文件和行号范围，确认后才继续调用模型。
- [x] 设置页提供持久化“AI 已关闭，仅本地分析”开关；关闭后问答不发起模型请求，索引、报告、关系图和符号查询仍可用。
- [x] GitHub 公开测试 Bug 表单要求版本、复现步骤和隐私确认，减少源码与凭据误上传。
- [x] `examples/sample-cpp` 可独立 CMake 构建；本机扫描与 Workbench 五类图查询均已跑通，Windows CI 也会重复该烟测。
- [x] CLI stdin 图查询与 MCP `cppinsight_graph` 协议转换代码；不静默截断参数。
- [x] C++ CTest、Rust 44 库测试 + 2 Workbench 测试 + 14 图协议测试、Clippy、TypeScript/Vite 和 release verifier。
- [x] 固定数据集 SVG 结构快照回归测试（稳定性、XML 转义、路径/中心节点高亮）。
- [x] GraphWorkbench 状态回归测试覆盖请求筛选/分页参数和多页节点、边、证据合并。
- [x] HTML 客户摘要独立转码测试覆盖标题、正文、视图标签的 HTML 转义和脚本载荷防护。
- [x] 桌面运行时检测回归测试覆盖浏览器预览与 Tauri IPC 桥接，避免把开发预览误报为原始 `invoke` 异常。
- [x] 浏览器预览模式下项目、示例和设置等桌面专属入口会禁用，并保留明确的桌面应用提示；已通过页面级冒烟验证。
- [x] Windows 制品 SHA-256 清单有跨平台校验器，拒绝绝对路径、路径穿越、重复条目、缺失文件和哈希不匹配。
- [x] 图基准结果校验器覆盖五类图、median/规模一致性和路径隐私；Windows CI 会对内置示例执行三轮基准烟测。
- [x] 质量基准候选清单固定 10 个项目并有结构校验；revision、许可证复核、人工准确率样本和真实结果仍待目标环境完成。
- [x] MCP SDK 安装后运行 `npm test` 通过（4/4，含真实 stdio initialize/tools/list 握手），无 SDK 的核心契约测试也可独立运行。
- [x] Windows CI 已接入 MSI/NSIS 安装、启动、卸载烟测脚本；待首个 Windows runner 运行产生证据。
- [x] 发布说明模板已覆盖版本、CI 证据、性能、已知限制、隐私、制品哈希和回滚版本；正式发布前必须填写真实结果。
- [ ] 核心/桌面许可证边界、版权主体、第三方声明和正式授权文件已由项目所有者确认（见 [`docs/licensing.md`](licensing.md)）。

## 目标环境发布门槛

- [ ] Windows runner 原生完成 Release 扫描器、Tauri MSI/NSIS 安装、启动、卸载、重装端到端测试。
- [ ] Windows artifact 生成 SHA-256 清单并在干净虚拟机核验。
- [ ] 正式发布包完成 Authenticode 签名并验证主体、时间戳和 SmartScreen 行为。
- [ ] 在 Windows 目标环境确认五类图的实际交互、缩放、布局和导出；缺包后备只用于源码开发环境。
- [ ] 在干净 Windows/CI runner 安装 MCP SDK 后运行传输测试，确认跨平台 stdio 行为。
- [ ] 发布包附带已确认的核心/桌面许可证和第三方声明；未完成前不得作为正式公开测试版分发。
- [ ] 在约定基准机运行 `scripts/benchmark-graph.ps1`，记录五类图延迟、内存、截断和准确率。
- [ ] 用不含客户源码的示例仓库完成首次安装、索引、报告、关系图、AI 关闭模式和脱敏诊断回归。

发布说明必须包含已知限制、性能实测、解析器启发式边界、隐私说明、artifact 哈希和回滚版本；未满足门槛时只能称为内部测试构建。
